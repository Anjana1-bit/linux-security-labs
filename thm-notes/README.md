### 🌐 What is Networking? (Day 4)
- **Category:** Network Fundamentals
- **Core Concepts:**
  - **The Internet:** A "Network of Networks" originating from the 1960s ARPANET project.
  - **Private vs. Public:** Private networks (LAN) use internal IPs; Public networks (WAN) use ISP-assigned IPs to communicate globally.
  - **Identifying Devices:**
    - **IP Address (Logical):** A temporary, software-based identifier.
      - *IPv4:* 32-bit (4.29 billion addresses) - currently facing exhaustion.
      - *IPv6:* 128-bit (340 undecillion addresses) - the modern solution.
    - **MAC Address (Physical):** A permanent 48-bit hexadecimal identifier assigned by the manufacturer.
- **Practical Lab:** 
  - **MAC Spoofing:** Demonstrated how an attacker can impersonate a trusted device by mimicking its hardware address to bypass network filters (e.g., Hotel Wi-Fi captive portals).
